FinnPRIO — Question Flow & Dependencies

Heikkilä et al. (2016) · Biological Invasions 18:1827–1842

★ Zero-forcing & sibling constraint: FinnPRIO source code (dag_values.py / dag_config.py), not stated explicitly in the paper

Entry section (ENT)

  • • 8 pathway types assessed independently; scores summed
  • • ENT2A/B are alternative versions of the same question
  • • ENT3 (trade volume) conditioned by ENT2 via Table 2 — very likely transport makes volume irrelevant
  • • ENT1 applies to pathways A–F only
  • • Code rule: ENT2B ≤ ENT2A (sibling constraint)

Critical dependencies

  • • EST1 = a: EST score = 0 → Total Risk = 0
  • • EST1 = a → IMP forced to 0 (code rule, not in paper)
  • • EST2 = a: SPR = 0 → EST = 0
  • • EST2 × EST3 → SPR via Table 3 non-linear lookup
  • • ENT2 → ENT3 via Table 2 conditioning

A vs. B — which to use

  • • INVASION-A ignores regulations — for deregulation scenarios
  • • INVASION-B includes measures — "more desirable when identifying pests deserving further regulation" (Heikkilä et al. 2016)
  • • Paper warns ENT2A is "less reliable" — predicting trade without regulations is "mostly guesswork"
  • • ENT2A is "less reliable" — predicting trade without regulations is "mostly guesswork"

Management (separate stream)

  • • MAN1 + MAN2 → Preventability
  • • MAN3 + MAN4 + MAN5 → Controllability
  • • Manageability = Prev × Ctrl (0–4 scale)
  • • Does NOT feed into Total Risk Score
  • • Used for: inspection design, surveillance targets, regulatory planning
